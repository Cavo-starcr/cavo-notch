# CAVO Notch

*[English](README.md) · Русский*

Челка MacBook как рабочий инструмент. Нативное приложение на SwiftUI/AppKit: в
покое его не видно, при наведении курсора оно разворачивается вниз в панель с
плеером, полкой для файлов, историей буфера обмена, заготовками, ближайшими
встречами, переводчиком, заметками и таймером.

**[Скачать для macOS](https://cavo.one/tools/notch)** — macOS 15 или новее,
Apple Silicon. Первый запуск требует одной команды, [почему](#установка).

```
0.0 % CPU в покое  ·  ≈40 МБ  ·  одно разрешение, и то по кнопке
```

## Что умеет

| Вкладка | Что делает |
|---|---|
| **Музыка** | Обложка, трек, исполнитель, полоса с перемоткой, назад / пауза / вперёд. Источник — **что угодно**, что видит сама macOS: плеер, вкладка браузера, любое приложение |
| **Полка** | Перетащи файлы в челку — они лежат там, пока не понадобятся; тянешь карточку наружу, и файл уходит куда нужно. ⌘-клик выбирает несколько, и перетаскивается вся группа. На карточке ещё быстрый просмотр (пробел или кнопка-глаз), копирование пути, отправка через AirDrop, переименование на месте и сжатие: одна карточка в свой архив, выделение — в один плоский `Archive.zip`. Скриншот, скопированный в буфер, сохраняется файлом и попадает сюда же, включая снятый на iPhone |
| **Буфер** | Последние 40 копирований; клик возвращает запись в буфер |
| **Заготовки** | Список того, что надоело перепечатывать — адрес, телефон, почта. Тот же список лежит в `~/Library/Application Support/CAVO Notch/snippets.json`, можно править прямо там |
| **Календарь** | Ближайшая встреча на неделю вперёд: сколько до начала и кнопка подключения к звонку — Zoom, Meet, Teams и остальные |
| **Перевод** | Печатаешь слева, перевод появляется справа — сам, без сети, средствами macOS |
| **Заметки** | Временные, в правом столбце: быстро записать, вернуться, удалить или унести через буфер. Пустые убирают себя сами |
| **Таймер** | 5 / 10 / 25 / 45 минут одним нажатием или помодоро: 25 минут работы сами передают в 5 минут перерыва. Пауза, +1 мин, стоп. Пока идёт, остаток стоит рядом с иконкой в меню-баре; заканчивается звуком и уведомлением. Отсчёт переживает перезапуск |

Панель открывается, когда курсор доходит до челки, и складывается, когда уходит.
Вкладки переключаются наведением, но только если курсор на иконке задержался —
пролетевший мимо не переключает ничего. При перетаскивании файла панель
открывается сама и сразу на полке. Иконка в меню-баре открывает панель, скрывает
содержимое вкладок для демонстрации экрана, включает автозапуск и закрывает
приложение.

На маках без челки тоже работает: панель считает челкой область 180 × 24 pt
вверху по центру экрана.

## Установка

Скачай DMG, перетащи **CAVO Notch** в «Программы» и один раз выполни:

```bash
xattr -cr "/Applications/CAVO Notch.app"
```

Иначе macOS может сказать, что приложение повреждено. Оно не повреждено. Apple
берёт деньги за Developer ID и нотаризацию; пока их нет, всё скачанное из сети и
не нотаризованное получает флаг карантина, а свежие версии macOS формулируют
отказ как «повреждено» вместо «неизвестный разработчик». Команда снимает этот
флаг с одного приложения и больше ничего в системе не меняет. Нужна один раз на
установку.

Подписанная и нотаризованная сборка готовится — тогда команда не понадобится.

## Требования

- macOS 15 или новее (вкладка перевода работает на Translation.framework)
- Apple Silicon
- Swift 6 для самостоятельной сборки (хватит Command Line Tools, полный Xcode не нужен)

## Сборка

```bash
git clone https://github.com/cavo-one/cavo-notch.git
cd cavo-notch
./Scripts/bundle.sh          # swift build + сборка .app + ad-hoc подпись
open "build/CAVO Notch.app"
```

`./Scripts/dmg.sh` собирает образ. `swift Scripts/make-icon.swift
Resources/AppIcon.icns` перерисовывает иконку — она генерируется кодом, поэтому
бинарного ассета, который надо держать в синхроне, нет.

## Приватность

Ничего не уходит с машины. Ни аккаунтов, ни телеметрии, ни сетевых запросов —
с одним исключением по выбору: переключатель погоды, выключенный по умолчанию,
раз в 20 минут спрашивает у Open-Meteo температуру города, который ты сам ввёл,
и не отправляет ничего, кроме координат. Единственное разрешение, которое
приложение вообще просит, — календарь, и только по кнопке на его вкладке. Название трека берётся из
системного Now Playing, а не из API плееров.

Скриншоты из буфера лежат в
`~/Library/Application Support/CAVO Notch/Screenshots` и не удаляются за твоей
спиной — в меню-баре видно размер папки и есть кнопка очистки.
