# Cyclop

Челка MacBook как рабочий инструмент. Нативное приложение на SwiftUI/AppKit: в покое
невидимо, по наведению мыши разворачивается вниз в панель с плеером, полкой для
файлов и историей буфера обмена.

```
0.0–0.1 % CPU в покое  ·  ~32 МБ RSS  ·  784 КБ бинарник  ·  1.1 МБ бандл
```

## Что умеет

| Вкладка | Что делает |
|---|---|
| **Музыка** | Обложка, трек, исполнитель, скраббер с перемоткой, prev / play-pause / next |
| **Полка** | Перетащи файлы в челку — они лежат там, пока не понадобятся; тянешь карточку наружу и файл уходит куда нужно |
| **Буфер** | История последних 40 копирований, клик возвращает запись в буфер обмена |

Панель раскрывается по наведению на челку и сворачивается, когда курсор ушел.
Во время перетаскивания файлов она раскрывается сама и сразу показывает полку.
Иконка в меню-баре — переключить панель, включить автозапуск, выйти.

## Требования

- macOS 14 или новее
- Swift 6 toolchain (полный Xcode не нужен, хватает Command Line Tools)

На маках без челки приложение тоже работает: панель считает челкой область
180×24 pt по центру верхней кромки экрана.

## Сборка

```bash
git clone https://github.com/akalikbergenov/cyclop.git
cd cyclop
./Scripts/bundle.sh          # swift build + сборка .app + ad-hoc подпись
open build/Cyclop.app
```

Иконка генерируется кодом, без графических редакторов:

```bash
swift Scripts/make-icon.swift "$PWD/Resources/AppIcon.icns"
```

## Разрешения

| Что | Зачем | Когда спросит |
|---|---|---|
| **Автоматизация** (Apple Events) | читать текущий трек и управлять воспроизведением в Apple Music / Spotify | при первом обращении к запущенному плееру |
| **Универсальный доступ** | *опционально* — эмуляция медиа-клавиш, когда ни Music, ни Spotify не запущены (браузеры и прочие плееры) | только если жмешь play при отсутствии скриптуемого плеера |

Наблюдение за курсором и история буфера обмена работают без разрешений вообще:
глобальный монитор событий мыши их не требует, а буфер читается через публичный
`NSPasteboard`.

## Как это устроено

**Окно.** Один `NSPanel` — borderless, non-activating, уровнем выше меню-бара,
`canJoinAllSpaces`. Он всегда одного размера (равен раскрытой панели) и никогда не
меняет frame: анимируется только содержимое. Клики вне видимой части проходят
насквозь через `hitTest`, возвращающий `nil` за пределами активной области. Так
получается плавная анимация без дерганья геометрии окна и без перехвата кликов по
меню-бару.

**Наведение.** Приложение — `.accessory` и никогда не становится активным, поэтому
`NSTrackingArea` не годится: окно не получает `mouseMoved`, пока приложение
неактивно. Вместо этого — глобальный монитор `NSEvent`, сравнивающий
`NSEvent.mouseLocation` с прямоугольником челки. Разрешений не требует, стоит
одну проверку вхождения точки в прямоугольник на движение мыши.

**Геометрия челки.** Ширина считается как `screen.frame.width` минус
`auxiliaryTopLeftArea` и `auxiliaryTopRightArea`, высота — из `safeAreaInsets.top`.
На тестовом MacBook Air M4 это 179 × 32 pt.

**Now Playing.** В macOS 15.4 Apple закрыла приватный MediaRemote энтайтлментом
`com.apple.mediaremote.external-access`, и `MRMediaRemoteGetNowPlayingInfo` теперь
отдает пустой словарь неподписанным приложениям. Поэтому основной источник —
публичный путь: distributed notifications (`com.apple.Music.playerInfo`,
`com.spotify.client.PlaybackStateChanged`) для событий плюс AppleScript для
состояния, обложки и управления. `MediaRemoteBridge` остался в сборке и
подхватывается автоматически там, где система его еще разрешает (тогда работают
и браузеры) — стоит это один `dlopen`.

**Цена простоя.** Таймер позиции трека тикает только во время воспроизведения,
опрос буфера обмена — это чтение одного счетчика `changeCount` дважды в секунду,
а сами данные читаются только когда счетчик сдвинулся.

## Ограничения

- Now Playing из браузеров (YouTube, веб-плееры) не читается: единственный API для
  этого — закрытый MediaRemote. Управление такими плеерами при этом работает через
  фолбэк на медиа-клавиши.
- Полка ссылается на файлы, а не копирует их: если переместить оригинал, карточка
  исчезнет при следующем запуске.
- Записи с типом `org.nspasteboard.ConcealedType` (менеджеры паролей) в историю
  буфера не попадают.
