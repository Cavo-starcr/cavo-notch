# Безопасность

## Как сообщить об уязвимости

Через [Security Advisories](https://github.com/akalikbergenov/cyclop/security/advisories/new)
на GitHub — это приватный канал, issue заводить не нужно. Ответ придёт, когда придёт:
проект личный, дежурства по нему нет.

## Что здесь вообще есть атаковать

Cyclop работает целиком на одной машине и никуда ничего не отправляет. Наружу
торчит ровно одна вещь, и только если её включить руками.

**Приём снимков с телефона** (`Ловить снимки с телефона` в меню-баре,
по умолчанию **выключен**) поднимает HTTP-слушатель на порту 17321.

Что он делает:

- отвечает только на `POST` по пути с секретом — шестнадцать случайных
  шестнадцатеричных знаков, сгенерированных на этой машине при первом включении;
- отбрасывает соединения с адресов вне локальной сети;
- принимает не больше четырёх запросов одновременно, даёт неопознанному
  соединению 5 секунд на запрос и обрывает заголовки длиннее 16 КБ;
- принимает не больше 40 МБ и распознаёт тип файла по содержимому, а не по
  тому, что заявил отправитель;
- пишет только в `~/Pictures/Cyclop`, именем из отметки времени: имя файла ни в
  какой части не берётся из запроса.

Чего он не делает: не шифрует. Трафик идёт обычным HTTP, поэтому в сети, где
кто-то может слушать чужие пакеты, секрет и картинка видны. Дома за роутером
этого достаточно; в открытом Wi-Fi приёмник лучше не включать, а пользоваться
AirDrop — ему сеть не нужна вовсе.

## Разрешения

Приложение запрашивает два, оба по делу и оба необязательные: Календарь — по
нажатию кнопки на вкладке «Календарь», папку «Загрузки» — для слежения за
AirDrop. Ни автоматизации, ни универсального доступа, ни записи экрана в обычном
режиме работы не требуется.

## Что читает Cyclop

Историю буфера обмена — она живёт только в памяти процесса и не пишется на диск.
Записи с типом `org.nspasteboard.ConcealedType`, которым менеджеры паролей
помечают свои копирования, в историю не попадают вовсе.
